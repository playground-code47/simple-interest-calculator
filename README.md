# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount over a specified period at a given rate of interest.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: Initial amount of money
- Rate: Annual rate of interest
- Time: Time period in years

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Features
- Calculates simple interest easily.
- Easy-to-understand formula.
- Accepts principal, rate, and time as inputs.
